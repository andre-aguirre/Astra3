# Astra3 for macOS

**Structural Analysis Toolkit for PDB Rendering Automation**

Astra3 is a PyMOL automation toolkit for reproducible structural analysis, visualization, and reporting.

## Requirements

- macOS 12 or later
- Apple Silicon Mac (M1/M2/M3/M4 or later)
- [PyMOL](https://pymol.org/) installed separately

Both open-source PyMOL and Incentive PyMOL are supported.

## Installation

1. Download the latest `.dmg` from the [GitHub Releases](https://github.com/andre-aguirre/Astra3/releases) page.
2. Open the `.dmg`.
3. Drag **Astra3** into your **Applications** folder.
4. Launch Astra3.
5. On first launch, select your PyMOL installation when prompted.

Astra3 is **Developer ID signed and notarized by Apple**. No Gatekeeper override should be required.
